# Ryan operations manual

## Use SRE

1. Install the official `SRE-Setup-x64.exe` and open **SRE** from the Start menu.
2. Connect FTEP in the browser, or finish offline setup for library/diagnostics only.
3. SRE creates a random local device identity; read and accept Accord 3.0, then review the library/runtime/system checks.
4. Pick a title and press **Set up**. Supply your own lawful game data. For BOTW/Switch titles, also select the external runtime executable you installed.
5. Review the honest compatibility badge. A supported badge applies to the exact title/variant/runtime combination only.
6. Press **Play**. Authorized launches require a valid signed device lease. Your first playable Zelda unlocks **Ahh, Zelda** locally and shows the overlay.

## If something fails

Open **Diagnostics**, follow the remediation, then export a sanitized report. Do not send ROMs, game files, saves, firmware, keys, tokens, or private-key files. Reconnecting can refresh an expired lease; reinstalling never grants an entitlement.

## Operate FTEP

Deploy only after PostgreSQL migrations, OAuth callback registration, production secrets, signing keys, GitHub release coordinates, security gates, and license review are complete. Admin pages live under `/admin`; unauthenticated users are redirected and APIs independently enforce roles. Suspension prevents future authorized launches and never deletes anything. Restoration permits a fresh lease.

## Publish SRE

Use the protected `SRE Windows release` workflow with a semantic version/channel. Inspect all five assets, checksums, manifest signature, installer lifecycle, and third-party notices before setting publish. Never substitute a test key or fake signature. Today, public redistribution remains blocked pending inherited Shipwright license confirmation.
